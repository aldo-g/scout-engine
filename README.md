# Scout Engine site

The public landing page for Scout Engine: startup scouting for accelerators, incubators and investors. A single static page (`index.html`) with its stylesheet, founder photo and partner logos under `assets/`, published on GitHub Pages.

There is no build step. Open `index.html` in a browser, or serve the folder with any static server, to preview it.

The scouting pipeline itself (LinkedIn search, screening, founder lookup, reports and the dashboard) is a separate project, `scout-engine-app`, which runs locally with its own server.
